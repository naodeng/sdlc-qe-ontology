# Workbench interface direction

## Surface and mode

Operate: a local quality workbench for reading delivery traceability and checking what evidence is available.

## Direction

The interface is a calm evidence atlas: a warm paper-like work surface, deep forest navigation, leaf-green trace links, and amber for states that have not been assessed. The earlier monochrome first pass was too stark and English-first; direct owner feedback set this revised direction. Arco Design React remains the component and interaction foundation.

## First view

The Overview opens in Simplified Chinese and provides an English switch. It shows the ontology's real Requirement → Acceptance Criterion → Test Obligation → Test Case → Test Execution → Test Evidence path, the bundled fixture's counts, and an explicit `尚未运行` validation status. The data is clearly marked as a repository example, not a project snapshot or quality decision.

## Visitor path

Overview → Ontology overview → Import plan → Quality analysis. Import and assessment routes explain their implementation status and avoid simulated upload, progress, or validation controls.

## Visual system

- **Palette:** canvas `#F3F6F2`, white surfaces, forest `#164C41`, leaf `#C9EDCE`, and amber `#FFF2D6` for unassessed status. Keep written labels alongside color so status never depends on color alone.
- **Typography:** Chinese system sans-serif for body copy, a system CJK serif for page headings, and monospace only for counts and identifiers. No remote font assets.
- **Composition:** compact forest side rail, calm title area, two clear summary panels, connected traceability steps, and a source/status row. Use restrained borders, soft corners, and light shadows to separate work areas.
- **Controls:** Arco buttons, menu items, tags, cards, and loading states with visible labels, high-contrast selected states, and keyboard focus.
- **Motion:** use brief hover feedback and a restrained loading indicator; honor reduced-motion preferences.
- **Responsive behavior:** retain the desktop side navigation at wide widths; at narrow widths use a labeled horizontal navigation row, stack the evidence path vertically, and avoid page-level horizontal overflow.

## Honest risk

Unassessed quality is shown with both the text `未知` / `尚未评估` and an amber surface, never as a pass/fail badge. Review contrast before adding new semantic colors.

## Product-wide reach

Apply the same Chinese-first labels, source-first hierarchy, trace colors, and explicit unknown states to the later import preview, mapping review, validation, snapshot history, and analysis surfaces.
