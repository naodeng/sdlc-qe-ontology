# dev-debug

Reproduce problem using a minimal fixture and pinned snapshot; inspect backend logs, API contracts, SPARQL result, SHACL validation, browser console, network and Playwright traces as appropriate. Never run untrusted data as code, never open unapproved remote connections, and scrub customer data from logs. Document cause, negative regression test and verified fix.

## Delivery
Provide touched files, exact commands and status, failure evidence, docs-sync results, security impacts and remaining risks.
