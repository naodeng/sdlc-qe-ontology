# dev-plan

Read AGENTS.md and relevant `docs/features`, `docs/designs`, ADRs and existing tests. Draft `docs/plans/YYYYMMDD-slug.md` from template with file impacts, dependency graph, mapping/API/ontology changes, expected RED tests, security, rollback, validation and docs sync. Explicitly label Draft, never quietly overwrite approved plans. Approval is a gate when modifying semantics or snapshot rules.

## Delivery
Provide touched files, exact commands and status, failure evidence, docs-sync results, security impacts and remaining risks.
