# 历史文档覆盖说明

**当前有效的产品决定优先级**：v0.18 > v0.17 > v0.16 > v0.15 > v0.14 > v0.12（同一主题发生冲突时）。

- v0.17 的「MVP 不含外部导入」被 v0.18 覆盖；但 GitHub/CI 在线集成仍不属于 MVP。
- v0.16/0.17 路线图「0.2.0 本地导入」被覆盖；0.2.0 改为增量、映射复用和差异诊断。
- v0.12 Animal Island UI 相关实施指引不再适用；v0.17 Arco 方向保持。
- 现有 ontology / SHACL / CQ / policy 文档保持候选状态，不因本轮产品决策自动获得验证通过。
- 本轮新增 `schemas` 只是候选 mapping schema，不是正式本体 URI/映射转换器实现。
