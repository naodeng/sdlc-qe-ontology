# 产品需求与验收范围（MVP v0.1.0）

## 核心用户旅程
创建/打开本地工作区 → 选择模板或文件 → 安全解析/预览 → 配置字段映射 → 人工确认 → 数据质量预检 → 语义转换 → SHACL/业务规则校验 → 查看差异和风险 → 确认发布不可变快照 → 分析需求/PR/Build/Release → 查看证据资格/未知原因 → 导出报告。

## 用户故事与验收
| ID | 用户故事 | P | 可验证完成标准 |
|---|---|---|---|
| WS-01 | 创建/切换项目工作区 | P0 | 目录校验、锁、空工作区、损坏 manifest 均有处理；不能跨工作区读写 |
| IMP-01 | 导入 CSV UTF-8 | P0 | 列头预览、引号/换行、重复列名、空文件、编码错误有确定结果 |
| IMP-02 | 导入受限 JSON | P0 | schema 校验、深度/大小限制、数组记录与嵌套字段策略明确 |
| IMP-03 | 导入受限 RDF | P0 | Turtle/受限 JSON-LD，禁止远程资源获取，解析失败隔离 |
| MAP-01 | 选择标准模板 | P0 | 模板 ID+版本固定，字段映射可查看并确认 |
| MAP-02 | 可视化字段映射 | P0 | 列到概念/属性、类型转换、必填约束、主键/外键映射、预览 |
| MAP-03 | 映射审批 | P0 | 仅用户显式确认可进入校验；更改映射后审批失效 |
| DQ-01 | 预检数据质量 | P0 | 缺失、重复、类型、非法引用、孤立节点、时区、构建/发布不一致 |
| VAL-01 | SHACL 与策略检查 | P0 | 缺依赖/失败/过期不得显示 verified；展示规则和来源 |
| SNAP-01 | 快照隔离与原子切换 | P0 | 失败前后 active snapshot hash 不变；切换有完整 manifest |
| ANA-01 | 质量评估 | P0 | 缺失证据和不完整性为 Unknown；Qualified 不等于 Verified |
| EXP-01 | 导出可追溯报告 | P1 | Markdown/JSON 带 snapshotId、policyVersion、验证状态 |

## 非目标
MVP 不做 AI 自主映射、任意 SQL/SPARQL 编辑器、GitHub 在线拉取、云端多租户、自动发布批准、跨系统实时同步、通用 ETL 设计器。可视化映射仅覆盖受控的概念和字段类型。

## 0.1.0 vs 0.2.0
0.1.0：一次性本地批量导入、手动字段映射、受控快照切换、单工作区内多快照（只读历史）。0.2.0：映射模板复用增强、批量数据差异比较、增量导入与冲突诊断（不承诺自动合并）。
