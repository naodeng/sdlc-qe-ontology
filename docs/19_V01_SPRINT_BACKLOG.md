## TDD 操作流程

```mermaid
flowchart LR
  CQ[确定能力问题与 gold 输出] --> RED[先写失败测试]
  RED --> GREEN[最小本体 / 查询 / shape]
  GREEN --> REFACTOR[重构]
  REFACTOR --> REVIEW[语义与来源复核]
  REVIEW --> EVIDENCE[记录测试证据]
```

## 任务完成定义 DoD

- 代码及本体变更附带至少一个失败先行测试或回归测试；
- 新术语有定义、示例、反例、来源及中英标签；
- 每项查询有确定的输入数据与期望输出；
- 不得把未知结果报告为“无风险”；
- 变更记录说明是否影响公开 IRI / 语义契约；
- PR 附 CI 日志和评审记录。
