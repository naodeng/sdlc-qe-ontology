# 技术方案与 Spike 验证

| 组件 | 候选技术 | 验证点 |
|---|---|---|
| 语言 | Python 3.12+ | 环境与 CI 一致性 |
| RDF | RDFLib | Turtle 解析、SPARQL、命名图支持 |
| OWL | OWL 2（选择 profile 待定） | 逻辑表达与推理代价 |
| 数据验证 | SHACL + pySHACL | 正反例、复杂约束、性能 |
| 推理 | OWL-RL / 独立推理器（候选） | 一致性、推理覆盖与性能 |
| CLI | Typer（候选） | 本地加载、验证、查询、报告 |
| 测试 | pytest | TDD、回归与测试数据隔离 |
| CI | GitHub Actions | lint、parse、SHACL、查询、docs |

## Spike-01 模型表达
对 10 个核心概念、15 个关系建模；验证 RDF/OWL 表达是否足够明确。输出示例 TTL 和术语定义。

## Spike-02 推理与约束边界
构造“缺少测试证据”和“错误类型”两个反例，分别验证 OWL 开放世界与 SHACL 完整性检查的差异。不得声称 OWL 自动发现缺失字段。

## Spike-03 查询与可追溯性
构造 3 条需求、2 个 PR、5 个测试义务及对应执行证据，验证查询可定位来源和时间。

## Spike-04 兼容与性能
在小型和中型合成数据集测试解析、查询、验证时延；记录环境和样本量，不预设性能结论。

## Spike 输出模板
假设 / 输入 / 操作步骤 / 预期 / 实际 / 日志与截图 / 结论 / 限制 / Go-No-Go。
