# 版本路线与阶段计划

| 阶段 | 建议时间 | 交付物 | Gate |
|---|---|---|---|
| Discovery | 1 周 | 术语表、竞品/标准调研、ADR | 关键语义歧义收敛 |
| v0.1 | 2 周 | core/sdlc/qe 基础模型、测试 | 解析、标签、基础约束通过 |
| v0.2 | 2 周 | alignment、SHACL、推理样例 | 正反例与兼容回归通过 |
| v0.3 | 2 周 | 通用软件研发数据集、查询 | 需求到发布链路可复现 |
| v0.4 | 2–3 周 | 变更影响与证据分析 CLI | 标注集评估可解释、可重复 |
| v1.0 | 2–3 周 | 文档、版本契约、CI、Eval | 证据审查通过后发布 |
| v1.x | 按需 | Agent 工具、外部适配器 | 独立质量门禁 |

以上为规划估算，需根据 Spike 结果调整，不代表实际完成进度。

## 依赖与退出条件
先模型契约，再跨域映射，再数据集，再分析，再 Agent。若基线模型存在逻辑冲突或不可复现，暂停下游功能。

## v1.0 发布检查
核心 URI 冻结；版本变更日志；许可证；中英说明；可复现数据；测试报告；已知限制；安全检查；示例运行说明；独立评审记录。
