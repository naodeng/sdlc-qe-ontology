# Current design facts

This directory separates current implementation facts from historical design proposals.

- `current-baseline.md`: accepted product direction, implemented bootstrap, and work that remains.
- `api.yaml`: current implemented bootstrap API contract. It covers read-only health and metadata only.
- `adr/`: durable decisions. Preserve prior records; add a new ADR when semantics or compatibility change.
- `ontology.md` and `import-mapping.md`: candidate documents until their corresponding Sprint 0 decisions and gates are complete.

Historical product packages remain under `ui-design/`. The v0.18 product baseline supersedes earlier product proposals; v0.19 governs repository structure and engineering workflow.
