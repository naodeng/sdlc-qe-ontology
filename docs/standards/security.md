# 本地优先安全规范

- 默认绑定 127.0.0.1；验证 Host 与 Origin；拒绝不可信 CORS；禁止 DNS rebinding；导入接口要求显式交互与安全校验。
- 拒绝 URL/路径探测、文件系统逸出、外部 RDF 实体解析、SSRF、压缩炸弹和超大图谱；数量、大小、深度、处理时间设限。
- 日志不记录用户上传原文、密钥、令牌或敏感内容，错误信息不泄露本机绝对路径。
- 快照指针修改必须可审计、受保护、原子且失败安全；旧快照保留以恢复。
- AI Agent 默认只读，无用户授权不得提交远程 GitHub 操作、修改数据或执行未知外部 MCP 命令。
- 依赖和 Figma/Arco 资产使用前核查许可与供应链来源；浏览器默认 CSP 与安全响应头。
