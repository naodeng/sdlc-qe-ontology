# Pull Request 质量检查

- [ ] 变更已关联需求 ID / ADR / Plan（若适用）
- [ ] 明确范围、被修改的源文件和兼容性风险
- [ ] TDD RED 证据与 GREEN 证据已附（未执行要说明）
- [ ] Python 单测/API 契约、RDF/SHACL/SPARQL、mapping schema 检查（适用项）
- [ ] 浏览器 E2E、dark/light、中文/英文、键盘可访问性（UI 变更适用）
- [ ] 导入安全、并发和失败后可恢复性（数据变更适用）
- [ ] docs/features、plans、designs、standards、qa 已检查同步
- [ ] 没有 secrets、个人数据、外部未审批资产
- [ ] 保留快照兼容性、回滚路径和 Go/No-Go 状态
