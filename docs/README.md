# Documentation map

The root agent contract is AGENTS.md. Read current product/design facts and applicable standards before changing behavior.

- features: versioned requirements and acceptance criteria.
- plans: task plans and execution records.
- designs: current API, product facts, and decisions.
- standards: engineering, security, ontology, testing, and documentation rules.
- qa: current test commands and evidence indexes.
- 01_* through 39_*: preserved project-history records from the supplied v0.19 package.
- ui-design: preserved historical product design packages; v0.18 is the current product decision baseline.

Historical plans and evidence do not establish current runtime or release readiness.
