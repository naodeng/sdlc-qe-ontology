# 开源治理与贡献规范

## 治理原则
公开设计讨论；语义变更必须评审；任何本体定义需要可理解的英文/中文说明；外部贡献优先提供最小复现和测试；禁止提交敏感数据。

## Issue 模板类别
概念提案、关系语义歧义、数据验证缺陷、兼容性问题、文档改进、实验结果、外部适配器需求。

## PR Checklist
- [ ] 问题与目标清楚
- [ ] 新增/变更 URI 有定义和双语标签
- [ ] 先写测试/反例
- [ ] SHACL、推理、SPARQL、兼容测试已运行
- [ ] 样例与文档同步
- [ ] 附证据与限制
- [ ] 评估破坏性变更和迁移
- [ ] 没有敏感数据和密钥

## 版本与发布
建议语义版本；OWL URI 的语义变化应比代码 API 变更更谨慎。发布记录应列出新增、弃用、破坏性修改及迁移方式。

## 许可证与安全
建议 Apache-2.0，但尚未确认；正式发布前添加 LICENSE、CONTRIBUTING.md、CODE_OF_CONDUCT.md、SECURITY.md。
