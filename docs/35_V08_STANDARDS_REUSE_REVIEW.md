# v0.8 标准复用与映射待决清单

| 本地术语 | 候选外部标准 | 当前决定 | 后续证据 |
|---|---|---|---|
| TestCase | OSLC QM | 暂不声明 owl:equivalentClass | 核对规范版本、URI、定义与 shape |
| Requirement | OSLC RM | 暂不声明等价 | 核对资源类型与语义 |
| CodeChange / PullRequest | OSLC CM | 只作概念级参考 | 确认是否存在语义兼容的对应资源 |
| TestExecution | PROV-O Activity | 已采用 rdfs:subClassOf，待审查 | 验证生命周期和身份定义 |
| TestEvidence | PROV-O Entity | 已采用 rdfs:subClassOf，待审查 | 核查来源和证据属性 |
| Build | PROV-O Activity | 实验性 subclass | 审查建模边界 |

不因术语相似而声明等价；许可证、规范版本与引用方式需要人工复核并记录来源。
